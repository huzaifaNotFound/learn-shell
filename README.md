# Learn Shell

**Learn Shell** is a browser-based interactive platform for learning Bash through lessons.
Instead of simply reading commands and examples, you will learn Bash by actually using a terminal, completing challenges, and progressing through structured lessons.

## Features

### Interactive Bash Terminal
Learn Shell includes a **Bash terminal engine built completely from scratch** for the browser.
You can interact with the terminal directly and practice commands without needing to install or configure a local shell environment.

### Step-by-Step Lessons
Lessons introduce Bash concepts progressively, starting with the fundamentals and building toward more advanced concepts.
Each lesson focuses on practical usage rather than just explaining syntax.

### Interactive Challenges
Challenges are integrated throughout the lessons.
After learning a concept, you can immediately use it in the terminal to solve a problem and verify your understanding.

### Keyboard-Only Interface(no tab key especially)
The entire website is designed to be operated **using only the keyboard**.
Navigation, lessons, terminal interaction, and challenges are built around keyboard controls, making the interface fast and accessible without relying on a mouse.

#LearnShell currently only supports bash, but in future more shell scripts will be added.
